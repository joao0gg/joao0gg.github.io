# joao0gg.github.io

Personal website, built with [Jekyll](https://jekyllrb.com) and the
[Academic Pages](https://github.com/academicpages/academicpages.github.io) theme.

## Preview

**Codespaces:** open a codespace and run

```shell
bundle exec jekyll serve --config _config.yml,_config_dev.yml
```

**Docker:** `docker compose up`, then open http://localhost:4000.

Pushing to `main` publishes the site.
